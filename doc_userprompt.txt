Extract structured data from the attached insurance policy schedule document 
and return it as a single JSON object matching the schema below exactly.

---

REQUIRED OUTPUT SCHEMA:



FIELD-SPECIFIC INSTRUCTIONS:
- CoverageScope: extract the note usually printed directly beneath the 
  document title, defining which sections/persons the policy covers.
- CoverSections: group every line item by its printed section number. A 
  section with multiple named items (e.g. Section One, Three, Six) must 
  produce multiple LineItems entries under ONE SectionNumber, not multiple 
  top-level sections.
- CoverSections[].LineItems[].LimitType: set to "NotOptedIn" if the printed 
  limit is £0 or equivalent; "Included" if the printed value is a word like 
  "Included" rather than a figure; "MonetaryLimit" otherwise.
- ItemisedValuables.ThresholdRules: extract even when the Items table is 
  empty — usually printed as a caption directly above/below the table.
- ItemisedValuables: if the table has two side-by-side Description/Value 
  column-pairs, read each column-pair fully before merging into one list.
- Endorsements.FreeTextEndorsements: only populate with genuinely bespoke, 
  policyholder-specific endorsement text — not the standard Excess or 
  Adjustments boilerplate, which belong in their own dedicated fields below.
- Endorsements.ExcessTerms / AdjustmentsClause: extract even when these are 
  printed under the "Endorsements" heading rather than their own heading — 
  set PresentAsEndorsement to true in that case.
- StatementOfFact.UnderinsuranceAverageClause: extract this clause verbatim 
  wherever it appears (commonly on a "Statement of Fact" page) — it directly 
  affects claim payment amounts and must not be paraphrased.
- StatementOfFact.ChangesInCircumstancesObligation: extract this even if a 
  similarly-worded Adjustments clause also exists under Endorsements — treat 
  them as two separate fields sourced from two separate locations.
- StatementOfFact.YesAnswerDisclosureDetails vs. ClaimsDisclosedByPolicyholder: 
  these are two DIFFERENT free-text boxes even though both may be blank in a 
  given document — do not merge them or infer one from the other.
- StatementOfFact.DeclarationQuestions: extract every Yes/No question exactly 
  as printed, in the order they appear, with its answer as a boolean.

Return only the JSON object. Do not include any text before or after it.
